GEO优化工具全开源版（免费）

一套面向 AI 搜索可见度优化的开源后台示例，包含运营后台、机构后台、商户后台、套餐续费、模型 Key 配置和支付参数配置。界面参考 shadcn/ui 的清爽后台风格。

查看中文 README 获取 API Key

shadcn 风格 UI

卡片、按钮、Badge、表单、侧边栏和深浅色模式，适合运营后台和 SaaS 工具。

机构 / 商户后台

机构可配置商户、有效期、套餐、平台权限和商户登录账号密码。

模型与支付配置

通过安装页或系统设置录入模型 API Key 和支付通道参数。

快速安装

  1. 上传项目到 PHP 站点目录。
  2. 确保 geo-data.json 和 config/config.php 可写。
  3. 访问 /install.php 填写后台账号、模型 Key 和支付参数。
  4. 访问 /index.php 登录运营后台。
  5. 访问 /merchant.php 登录商户后台。
