Install and Get API Keys

This project does not include production keys. Create keys in your own service accounts and save them through /install.php.

DeepSeek

Create an API key and fill deepseek_api_key.

Alibaba Bailian / DashScope

Create an API key and fill dashscope_api_key.

Volcengine Ark

Create an API key and fill volcengine_api_key.

Tencent Hunyuan

Create an API key and fill tencent_hunyuan_api_key.

Payment Channel

Fill merchant number, AppId, merchant key, and configure /pay_notify.php.
