安装和获取 API Key

本开源版不会内置任何正式密钥。请在自己的服务商账号中创建 Key，然后通过 /install.php 或运营后台的系统设置保存。

DeepSeek

用于 DeepSeek 问答监测、品牌提及检测和复测。

打开 DeepSeek API Keys

阿里百炼 / 通义千问

用于千问兼容接口监测。进入阿里云百炼控制台后创建 API Key。

打开阿里云百炼控制台

火山方舟 / 豆包

用于豆包模型接入点监测。进入火山方舟控制台创建 API Key 或接入点。

打开火山方舟控制台

腾讯混元 / 元宝

用于腾讯混元检测链路。通常需要在腾讯云 CAM 中创建 SecretId / SecretKey。

打开腾讯云 API 密钥管理

支付通道

在你的支付服务商后台获取商户号、AppId、商户 Key，并配置异步通知地址 /pay_notify.php 和同步返回地址 /merchant.php。
